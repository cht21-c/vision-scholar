# 本轮目标：可独立说明、可复验、可公开展示的原创工程

用户要求：进一步增加原创内容，完整运行实验与实战演示，形成有数据、结果和证据的GitHub成果。此前V0/V1/V2的结果保留，不把它们改写成新版本结果。

当前判断：已有内容可作为应用工程项目写进简历；核心循环仍来自OpenHarness，V2主要是领域层补充。应增强可拆卸的运行机制和真实科研闭环，而不是靠代码行数或技术名词声称原创。这里的原创指本项目独立设计/实现的工程贡献，不宣称算法首创或学术新颖性。

## 已确认的不足

- 低成本压缩会遗漏修正；LLM摘要在小型压力测试中可超时，完整用量也可能缺失。
- V2只保护关键词命中的用户原句，还不能解释一个请求为什么保留/丢弃某段历史。
- 上游同批工具直接并行，写入与随后读取没有依赖屏障；事件缺少完整call ID和单工具真实执行区间。
- 实验以单seed的digits教学演示为主，尚缺从预设方案到多seed、干扰条件和结论边界的闭环。
- 测试集主要用于开发，没有严格区分新一轮开发集与留出集。
- 当前目录尚非Git仓库；依赖相邻上游、评测资料位于被忽略的data目录，尚不适合直接公开。

## 实施范围

### A. 独立 ResearchEngine

新增`research`运行版本（V3）。不调用或包装QueryEngine，不继承LegacyEngine执行逻辑；共有传输、消息DTO与领域工具接口可以继续复用并注明归属。

1. **有预算的上下文组装**：保留完整本地历史，仅为模型请求构造视图。按完整用户轮组织消息、保护当前请求与用户决策原句、选择相关/近期历史；大工具结果保存为内容寻址工件，在上下文内保留引用和有界预览，允许模型按ID重新读取。明确使用字符预算与估计，不冒充供应商真实token计数。若不可裁剪的必要内容超预算，返回明确错误；不静默截断用户请求或破坏tool-call配对。不调用LLM摘要。
2. **读并行、写屏障**：模型声明的调用顺序具有执行语义；连续只读调用有界并行，写入成为前后屏障，后续读必须等前面的写完成。未知工具/非法Schema返回对应call ID的错误结果；取消不继续下轮模型。为每个调用保存真实起止时间、参数、结果/工件SHA和错误。
3. **可拆卸实验开关**：完整历史/预算组装、串行/直接并行/写屏障分别控制。使用相同请求和工具做消融，不能将工具Schema变化或模型变化算作运行循环的收益。

已有V2决策抽取可复用并明确标为既有模块。本轮不声称已解决任意自然语言决策抽取、语义蕴含、全部提示注入、任意副作用exactly-once或进程崩溃自动续跑。

### B. 视觉研究实验闭环

新增固定CPU视觉鲁棒性研究：比较原始像素与PCA特征的SVM，在clean、固定高斯噪声、固定遮挡条件下评估；使用至少3个预先指定seed。

- 先创建不可变方案，绑定参数、候选超参、数据/代码指纹；执行按方案ID。
- 每seed保留独立train/validation/test索引，scaler/PCA只拟合train，C只按validation选择，随后评估test。
- 相同seed/条件的两个方法使用同一测试样本与干扰，实现配对比较。
- 保存逐样本预测、分割与干扰SHA、每seed指标；报告跨seed均值/标准差及固定测试集上的配对bootstrap区间。跨seed测试集重叠，不能当成独立新增样本或泛化统计证明。
- 相同方案的重复执行复用已完成结果；并发执行受数据库状态约束。失败/中断状态明确，不虚构完成。
- 提供领域工具与实验室UI：方案→运行→指标→原始证据→可导出报告。表格由Python生成，模型用于解释，不能编造实验成功或结果。
- 数据集仍是digits，明确为小型真实视觉实验；不伪装复现大规模CV论文。

### C. 可公开成果

整理一个自包含的GitHub仓库：英文/中文说明、原创/复用矩阵、架构、完整Prompt、安装与离线CI、公开评测数据、实验复现命令、演示截图或录像、已知局限与许可证归属。

私有凭据、endpoint标识、个人会话、简历、模型权重、原始PDF和运行数据库不进入仓库。公开评测导出使用白名单字段，保留trace链路和hash；论文原文通过可复现下载取得。公开数据不引用开发机器绝对路径。

GitHub实际创建/推送在本地仓库与成果完整后执行；使用用户现有身份。若没有可用登录，仅在最后请求必要的账户授权，不把本地准备称作已经发布。

## 实验顺序与判定

1. 先冻结开发/留出样本清单、seed、Prompt、判据及文件hash，再实现V3。留出集不用于调整策略；如失败后改策略，原留出集转为开发证据，并生成新的独立留出批次。
2. 小样验证传输、工具Schema与真实研究实验，再执行完整批次；并发从4开始，逐题原子保存和打印ETA，不重跑挑选结果。
3. 正常论文/源码/记忆/研究任务：V2与V3使用相同模型、Prompt、工具和检索。报告必要动作、引用/数值、参数合法、错误恢复、延迟与全部API usage。
4. 上下文：与完整历史、V2及V3预算组装比较。使用不同主题、随机标识、修正位置、干扰来源和查询长度；同时测关键事实、消息配对、请求预算、重读次数、隐藏摘要调用与时间。
5. 调度：相同工具调用清单回放串行/直接并行/写屏障；检验“保存后读取”、并行一项失败、错误Schema、取消、并发上限。人工延迟结果只说明调度机制。
6. 研究闭环：执行真实多seed实验，校验分割与指标可重算、同方案复用、失败状态、论文证据到实验假设的边界；最终浏览器执行真实模型驱动的研究任务。
7. 生成中文Excel（蓝底白字、首行冻结、筛选）与机器可读结果。AI语义复核与工程判据分离，不称人评金标，不预先承诺所有指标提升。

完成标准：代码机制接入实际应用；新测试与已有回归通过；真实演示完成；结果与失败可回查；干净目录安装/离线测试可复现；公开仓库材料自包含，实际发布状态准确。
